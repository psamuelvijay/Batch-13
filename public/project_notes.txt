────────────────────────────────────────────────────────────────────────────────
WHAT THIS PROJECT IS
────────────────────────────────────────────────────────────────────────────────
An IoT Intrusion Detection System that detects cloned/compromised ESP32 devices
using behavioral fingerprinting rather than identity checks. Two ESP32s with
DHT11 sensors send telemetry over MQTT. A FastAPI backend runs rule-based +
ML detection. A React dashboard shows live results. A Merkle tree provides
tamper-proof local logging. Hyperledger Fabric is the optional blockchain layer.

Key insight: even if an attacker clones a device's UID and firmware hash,
they cannot perfectly replicate its behavioral patterns (interval timing,
sensor deviations). That's what ML is trained to catch.

────────────────────────────────────────────────────────────────────────────────
FOR FUTURE DEVELOPERS — IMPORTANT
────────────────────────────────────────────────────────────────────────────────
- Always run backend from backend/ folder, not root. Imports are relative.
- data.csv must be in backend/ folder before running dataset_builder_v2.py.
- The ground truth label is the source tag (ghost/legit), NOT the verdict field.
  Do not change this without understanding why — old verdict-based labeling
  caused 100% fake accuracy because stealthy ghost packets were labeled TRUSTED.
- Rolling windows MUST be grouped by source/device. Global rolling = data leak.
- Train/test split MUST be time-based. Random split on this dataset = data leak.
- SMOTE must run inside CV folds only, not before CV.
- Ghost ESP32 uses LEGIT UID for all attacks — this is intentional. The whole
  point is that ML must detect clones from behavior, not identity.
- TRAINING_MODE=True disables quarantine. Keep it True during data collection.
  Switch to False only in production/demo.
- HLF requires Linux (WSL2). Do not try to run peer CLI on Windows natively.
- The duplicate app=FastAPI() bug was the CORS killer — never add a second
  app definition in telemetry_api_v3.py.
- LEGIT_UID = "D00061FE8CE0", LEGIT_FIRMWARE = "dfc2dcd4" — hardcoded in both
  firmware and backend. If you re-flash with a new chip, update all 3 places.
